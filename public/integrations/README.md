# Logos das integrações

PNGs normalizados (altura 96px, largura proporcional, fundo transparente) gerados a partir
dos arquivos originais. O mapeamento nome → arquivo fica em `src/lib/data.ts` (`LOGOS`).

Para adicionar/trocar um logo: salve `<slug>.png` aqui com altura 96px e adicione a entrada em `LOGOS`.
Plataformas sem arquivo (ex.: Doppus, Meta Ads) usam um monograma na cor da marca.
